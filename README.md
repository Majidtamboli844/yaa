# YAA Company Website

A responsive multi-page website for YAA Company, built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — home page with all services, about section and enquiry form.
- `services/` — 20 individual service pages.
- `styles.css` — responsive styling.
- `app.js` — page content, navigation and email enquiry behaviour.
- `assets/logo.png` — supplied YAA Company logo.
- `assets/company-poster.jpeg` — supplied services poster.

## Run locally
Open `index.html` in a modern browser. For best results, use a simple local web server (for example VS Code Live Server).
